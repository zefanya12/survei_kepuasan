⚠️ Cara menghubungkan Google Spreadsheet sebagai database survei:
🔧 Langkah-langkah Setup
Langkah 1 — Buat Google Spreadsheet
Buka sheets.google.com → buat spreadsheet baru → beri nama Survei Lapas Lirung. Buat dua sheet: Penilaian dan Konten.

Di sheet Penilaian, buat header di baris 1:
Timestamp | Layanan | Penilaian | Saran
Langkah 2 — Buat Apps Script
Di spreadsheet → menu Ekstensi → Apps Script → hapus kode lama → paste kode berikut:
const SS_ID = SpreadsheetApp.getActiveSpreadsheet().getId(); function doPost(e) { const data = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.openById(SS_ID).getSheetByName("Penilaian"); sheet.appendRow([ new Date().toLocaleString("id-ID"), data.layanan, data.penilaian, data.saran || "" ]); return ContentService.createTextOutput(JSON.stringify({status:"ok"})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { const action = e.parameter.action; const ss = SpreadsheetApp.openById(SS_ID); if (action === "getSurvei") { const sheet = ss.getSheetByName("Penilaian"); const rows = sheet.getDataRange().getValues(); const data = rows.slice(1).map(r => ({ timestamp: r[0], layanan: r[1], penilaian: r[2], saran: r[3] })); return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); } if (action === "getKonten") { const sheet = ss.getSheetByName("Konten"); const rows = sheet.getDataRange().getValues(); const obj = {}; rows.forEach(r => { if(r[0]) obj[r[0]] = r[1]; }); return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } if (action === "saveKonten") { const sheet = ss.getSheetByName("Konten"); const konten = JSON.parse(e.parameter.data); sheet.clearContents(); Object.entries(konten).forEach(([k,v]) => sheet.appendRow([k, v])); return ContentService.createTextOutput(JSON.stringify({status:"ok"})) .setMimeType(ContentService.MimeType.JSON); } return ContentService.createTextOutput("ok"); }
Langkah 3 — Deploy sebagai Web App
Klik Deploy → New Deployment → pilih tipe Web app → set:
• Execute as: Me
• Who has access: Anyone
Klik Deploy → izinkan akses → salin URL Web App.
